# 07 カーネル層 PoC：終了証拠の書き手を実行対象から切り離す（Landlock）

2026-09-24・母艦。02-threat-model.md §6 の候補「終了証拠の書き手を実行対象から隔離すること」の最初の試作。
コード: `kpoc/landlock_mitodoke.py`（単体。guardrun にはまだ組み込んでいない）

## 何をしたか
guardrun の見届け役は命令と同じ権限で終了の証拠（見届け.txt）を書くので、命令は証拠を偽造・消去・
差し替え・切り詰めでき、見届け役を殺せる。今はこれを外から見た終了コードとの突き合わせで**後から**見抜いている。

Linux の Landlock（特権不要の LSM）を**命令の側だけ**に掛けた：
- 作業場の外への書き込み系（書く・消す・作る・名前を変える・切り詰める）を禁止
- ドメインの外のプロセスへのシグナルを禁止（ABI 6 の scoped）
見届け役は掛けないまま証拠を書く。**断るのはカーネルで、その場で。**

## 判定基準（走らせる前に書いた）
攻撃5種が Landlock なしでは成功し、ありでは全部カーネルに断られ、証拠が本物の終了コードと一致すること。
1つでも通ったらそのまま報告する。上乗せは100回の中央値。

## 結果（OrbStack Linux 7.0.14・Landlock ABI 8・docker 既定の seccomp・特権なしの利用者）

| 攻撃（命令は本当は exit 3） | Landlock なし | Landlock あり |
|---|---|---|
| 証拠を偽造（「終了 0」を書く） | 通った | EACCES |
| 証拠を消す | 通った | EACCES |
| FIFO に差し替え | 通った・**見届け役が固まった** | EACCES |
| 切り詰め | 通った | EACCES |
| 見届け役を SIGKILL | 通った | EPERM |
| **証拠が本物と一致** | **0/5** | **5/5** |

- 掛ける手間: 100回で中央値 88.5 µs・最大 137.0 µs（fork 後・exec 前の子で ruleset を作って掛けるまで）
- 正当な作業（作業場の中で書く・mkdir・rename・unlink）は全部通り、終了コードも正しく記録された（t_legit.py）

## 言えること・言えないこと
- 言える: 同じ uid のままでも、**証拠の書き手と実行対象をカーネルで分けられる**。今の「後から見抜く」を
  「その場で断る」に置き換えられる。特権も新しい uid も要らない。
- 言えない: 1台（OrbStack の VM）・5攻撃・1回ずつ。本物の Ubuntu / 古いカーネル（ABI<6 はシグナルを止められない）では未測定。
  guardrun に組み込んだ状態（bwrap・別ユーザとの重ね）も未測定。読み取り（秘密）はこの PoC の対象外。
- 未踏への書き方: 「Linux の Landlock で終了証拠の偽造・消去・差し替え・切り詰め・見届け役の停止の5種を
  カーネルで拒否（対照では5/5成功）、上乗せ中央値 88.5µs（n=100）」。**台数・攻撃数を必ず添える。**

## guardrun への組み込み（同日・~/bin 0acd18a）
見届け役が命令の側だけに Landlock を掛ける形で `~/bin/guardrun.py` に入れた。手元の Linux（kpoc/Dockerfile・run-linux.sh で再現）で、
印の試験の「記録を狙う」6件が 直す前: 攻撃が通り外から中断で見抜く → 直した後: 全部カーネルが拒否・記録は無傷。
実測 12/12・被害0、上乗せは 24→21ms（誤差の範囲・Landlock の分は µs 単位）。Mac は道が変わらない。
本物の Ubuntu（GitHub）は Actions の上限で未確認。

## 限界：Landlock の版が 6 より前の機械（2026-09-26・母艦）
シグナルの囲い（scoped）は Landlock ABI 6（カーネル 6.12）から。**実際に使われる多くの Linux はそれより前**
（Ubuntu 22.04 の標準 5.15＝版 1、24.04 の 6.8＝版 4）。そこでは：

| 攻撃 | 版 1〜5 | 版 6 以上 |
|---|---|---|
| 記録の偽造・消去・差し替え・切り詰め | その場でカーネルが断る | その場でカーネルが断る |
| 見届け役を殺す | **断れない。外から見た終了コードとの突き合わせで「中断」と後から見抜く** | その場でカーネルが断る |

- 殺されても嘘の「緑」にはならない（記録は書き換えられないので、偽の成功は残せない）。できるのは「中断」にすることだけ。
- 版 6 未満でもその場で断る方法（別の仕組みで親へのシグナルを止める）は、この段階では入れていない。
- 未踏への書き方: 「版 6 以上ではカーネルがその場で断る。版 1〜5 では偽造は断り、見届け役の停止は後から中断として検出する」。
  **手元で測ったのは版 8 の機械だけ**で、版 1〜5 の本物は未測定（GitHub の Ubuntu で測る予定: ~/未踏/実測/windows検証 の L1）。
