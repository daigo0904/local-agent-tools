# 再現コーパスの発火確認（2026-09-26・Codex）

## 実装

`comparison/cases.json` に、初期ファイルの全文・発火用Pythonコード・期待する全ファイルの種類/内容/modeを持つ8ケースを固定した。

- 攻撃4件: 終了記録の偽造、削除、切り詰め、FIFOへの差し替え。
- 正当操作4件: 作業場のファイル作成、ディレクトリ作成、rename、unlink。

これは旧13件の事故の再現ではなく、新規の合成コーパス。期待する正当性が分からない旧「青67件」から正当ケースを推定することも避けた。同じ初期状態に対する許可操作を明示して対照にした。

`comparison/run.py` は各ケースを新規一時フォルダで走らせ、初期/最終状態、所有者、argv、操作ハッシュ、終了コード、標準出力/エラー、壁時計を保存する。完了時に件数・ログバイト数・SHA256を保存し、ケース定義と実行器自身もコピーする。再確認用の `--check` を備える。

## 事前基準と結果

判定基準は実行前に `comparison/README.md` に記載した。

| 確認 | 結果 |
|---|---|
| A（防御なし）1回目 | 攻撃4/4発火、正当操作4/4達成、計8/8一致 |
| A（防御なし）2回目 | 攻撃4/4発火、正当操作4/4達成、計8/8一致 |
| 両実行の操作・初期状態・最終状態 | 全8ケースで一致 |
| 2秒sleepを0.05秒で打ち切る例外経路 | タイムアウト検知、プロセス回収を確認 |
| ログを1バイト削る例外経路 | 完了検証が拒否 |

各実行は終了コード0、8件のログと完了マーカーを確認。各ログは空から12,863バイトに増えた。証拠は `comparison/results/A-20260926-1/` と `A-20260926-2/`。推論は呼んでいない。

## 限界と次

Aの発火確認のみ。防御できた数・誤拒否率・B/Cの時間比較は未測定。単体PoCの数値と混ぜない。macOS、同一uid、新規フォルダ、明示的なACL設定なしのケース。継承ACLは記録していない。旧13件の再現可能件数は0件のまま。

B/C用に、同一バージョンの比較専用コピーを固定してLandlock適用の有無を変える。運用中のguardrunには無効化スイッチを設けない。記録の置き場所が実際の見届け役の配置と一致するようアダプターを作り、A/B/Cで操作が同じ、B/Cで執行が異なることを実測してから本計測する。旧 `kpoc/run-linux.sh` は過去の一時フォルダをハードコードしているため、今回の再現用経路には使っていない。
